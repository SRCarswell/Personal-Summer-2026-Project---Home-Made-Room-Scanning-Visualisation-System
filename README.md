# Summer 2026 Project - Home-Made Room Scanning & Visualisation System
As a personal summer project I designed and built a low-cost room scanning system, covering light programming in Arduino, time-of-flight sensor integration, serial data acquisition, and Python-based point cloud processing and 2D & 3D visualisation. This project was carried out in my spare time during the summer between my 3rd and 4th year of study.
